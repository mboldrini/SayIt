# SayIt — English Pronunciation Trainer

A progressive web app for training English pronunciation, built for personal use on Android tablets and phones. Uses the Web Speech API for real voice recognition and Speech Synthesis for pronunciation demos — no backend, no subscriptions, no accounts.

![SayIt](https://img.shields.io/badge/PWA-ready-630ed4?style=flat-square) ![React](https://img.shields.io/badge/React-19-61dafb?style=flat-square) ![Vite](https://img.shields.io/badge/Vite-8-646cff?style=flat-square) ![Tailwind](https://img.shields.io/badge/Tailwind-3-06b6d4?style=flat-square)

---

## Features

- **40 exercises** across 4 categories — Tongue Twisters, Word Power, Daily Phrases, and Cork Training
- **Voice recognition** via Web Speech API (Chrome/Android) with instant scoring: Perfect / Good / Retry
- **Pronunciation demo** — tap to hear any phrase spoken at natural speed
- **Cork Mode** — trains articulation with a physical wine cork between front teeth
- **XP & streak system** — gamified progress saved to localStorage, persists across sessions
- **Exercise completion tracking** — "Done" badge on completed cards, "Not Done" filter to see what's left
- **Progress modal** — full breakdown by category, total XP and streak at a glance
- **Category + difficulty filters** with combined filtering (e.g. "Daily Phrases + Easy")
- **PWA** — installable on Android home screen, works fully offline after first load
- **No account required** — all progress lives on the device

## Running Locally

```bash
cd app
npm install
npm run dev
```

Open Chrome (required for Web Speech API). The app runs at `http://localhost:5173`.

> Voice recognition requires a browser that supports the Web Speech API — Chrome and Chrome-based browsers on Android work best.

---

## Building for Production

```bash
cd app
npm run build
```

Output goes to `app/dist/`. Upload the contents of `dist/` to your hosting root (Hostinger, Vercel, Netlify, etc.).

The build includes a service worker (`sw.js`) generated by Workbox that caches all assets for offline use.

## Scoring Logic

Each phrase attempt is scored by comparing the speech recognition transcript to the target phrase word-by-word:

| Score | Condition | XP |
|---|---|---|
| Perfect | ≥ 85% word match | +30 |
| Good | ≥ 55% word match | +15 |
| Retry | < 55% word match | +5 |
| Completion bonus | All phrases done | +50 |

Retrying a phrase only awards XP for improvement over the previous attempt (no XP farming on repeated retries).
